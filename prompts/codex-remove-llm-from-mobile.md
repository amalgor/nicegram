# Codex Task: Remove embedded LLM from mobile app

## Context

The embedded LLM (Qwen 2.5 GGUF via `llama-cpp-2`) was never used meaningfully in the mobile app. It adds ~500 MB to APK size and caused OOM crashes. We're removing it from the mobile build while keeping `hydra-ai` available for server-side / desktop builds.

The AI functionality will be reimplemented as a separate "Hydra AI Assistant" app (future project). See `hydra-architecture-review-3ce054.md` section "Two-App Strategy (2026-04-04)".

## What to do

### Step 1: Feature-gate `hydra-ai` in `hydra-core`

**`hydra-core/Cargo.toml`:**
- Make `hydra-ai` an optional dependency: `hydra-ai = { path = "../hydra-ai", optional = true }`
- Add feature: `[features]` section with `ai = ["dep:hydra-ai"]`

**`hydra-core/src/lib.rs`:**
- Conditionally import: `#[cfg(feature = "ai")] use hydra_ai::AiNegotiator;`
- When feature is off, remove `ai: Arc<AiNegotiator>` from `Socks5Server` struct and `new()` signature. It's already `#[allow(dead_code)]` — not used in any hot path.
- Alternative: create a minimal stub type `pub struct AiStub;` and use it when feature is off.

**`hydra-core/src/main.rs`:**
- This is the server binary, should enable `ai` feature. Gate the AI init block with `#[cfg(feature = "ai")]`.

### Step 2: Remove `hydra-ai` from mobile Rust

**`hydra_mobile/rust/Cargo.toml`:**
- Remove line: `hydra-ai = { path = "../../hydra-ai" }`
- Ensure `hydra-core` dependency does NOT enable `ai` feature (no `features = ["ai"]`)

**`hydra_mobile/rust/src/api/model_manager.rs`:**
- DELETE this entire file.

**`hydra_mobile/rust/src/api/mod.rs`:**
- Remove line: `pub mod model_manager;`

**`hydra_mobile/rust/src/api/simple.rs`:**
- Remove `use hydra_ai::AiNegotiator;` import
- Remove `SHARED_AI` references (they were in `model_manager.rs`)
- Remove `analyze_connections()` function entirely
- Remove `analyze_host()` function entirely
- In `start_hydra_node()`: remove `let ai = Arc::new(AiNegotiator::new(...))` and `SHARED_AI` population
- In `init_extension_runtime()`: same cleanup
- Adjust `Socks5Server::new(...)` call — remove `ai` parameter (matches Step 1 changes)

### Step 3: Remove LLM-related Flutter UI

**`hydra_mobile/lib/screens/models_screen.dart`:**
- DELETE this entire file.

**`hydra_mobile/lib/src/rust/api/model_manager.dart`:**
- DELETE this file (FRB codegen will not recreate it).

**`hydra_mobile/lib/main.dart`:**
- Remove any import/reference to `models_screen.dart`
- Remove "AI Models" tab/navigation entry if present

**`hydra_mobile/lib/screens/connect_screen.dart`:**
- Remove "Security Analysis" card that calls `analyzeConnections()` or displays LLM output
- Keep the rest of the Connect screen intact

**`hydra_mobile/lib/screens/connections_screen.dart`:**
- Remove async LLM analysis calls (`analyzeHost()`)
- Remove any "AI recommendation" display widgets
- Keep connection list, grouping, proxy toggle — all non-AI functionality stays

**`hydra_mobile/lib/src/rust/api/simple.dart`:**
- Remove `analyzeConnections` and `analyzeHost` function stubs
- (This file will be regenerated by FRB codegen, but remove manually if not running codegen)

### Step 4: Regenerate FRB bindings

```bash
cd hydra_mobile
flutter_rust_bridge_codegen generate
```

This will regenerate:
- `lib/src/rust/frb_generated.dart`
- `lib/src/rust/frb_generated.io.dart`
- `lib/src/rust/frb_generated.web.dart`
- `lib/src/rust/api/simple.dart`
- Remove stale `lib/src/rust/api/model_manager.dart` if codegen doesn't clean it up

### Step 5: Verify

```bash
# Rust compilation without AI
cargo test -p hydra-core --no-default-features
cargo test -p hydra-core --features ai  # server mode still works

# Mobile crate compiles without llama-cpp-2
cargo check -p rust_lib_hydra_mobile

# Flutter
cd hydra_mobile
flutter analyze
flutter test
flutter build apk --release
```

Check that the release APK is significantly smaller (should drop ~20-50 MB from the binary itself, plus no GGUF model download prompt).

### Step 6: Update documentation

In `SERVICE_MANUAL.md`:
- Update crate descriptions: `hydra-ai` is now server-only
- Remove references to mobile LLM, model_manager, analyze_connections/host
- Note that AI functionality will be in separate Hydra AI Assistant app
